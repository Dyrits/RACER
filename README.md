# Racer

A 2D racing game built with Java, as a CodeGym game task.

## About The Project

From the original README: this project is a [CodeGym](https://codegym.cc/) game task. The game is a racing game in the spirit of classics like Donkey.bas: steer left and right, accelerate, and dodge other cars and obstacles to reach the finish line. The original assignment text is preserved in [ASSIGNMENT.md](ASSIGNMENT.md), and the game can be tried on [CodeGym](https://codegym.cc/projects/apps/30337).

From the author's notes: the project was made from scratch following specific instructions, and several elements (such as the game engine) were provided by the course.
